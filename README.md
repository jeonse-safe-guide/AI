#🤖 전세 안심 길잡이 - AI (Jeonse Safe Guide - AI)


등기부등본을 분석해 전세 사기 위험을 예측하는 AI 파트입니다.
등기부등본을 OCR로 읽어 위험 요소를 뽑아내고, 공시지가·시세와 비교해 위험도를 알려줍니다.




#📌 주요 기능 (Features)


📄 등기부등본 OCR — 이미지/PDF 등기부등본에서 텍스트 자동 추출
✅ 위험 체크리스트 — 근저당권, 압류·가압류, 신탁 등 위험 요소 자동 점검
📊 위험도 예측 — 보증금 대비 공시지가·시세를 비교해 깡통전세 위험 산출
