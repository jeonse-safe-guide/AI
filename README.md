# 🏠 전세 안심 길잡이 (Jeonse Safe Guide)

**안전한 전세 계약을 위한 AI 기반 리스크 분석 및 가이드 서비스**
> 복잡한 등기부등본 분석부터 계약 체크리스트까지, 누구나 쉽게 전세 사기를 예방할 수 있도록 돕습니다.

## 주요 기능

### 1. OCR
등기부등본 이미지에서 근저당권, 압류, 신탁 등 권리관계를 자동으로 추출합니다. (Qwen2.5-VL-7B)

### 2. 위험 체크리스트
추출된 권리관계를 바탕으로 계약 전 확인해야 할 항목을 생성합니다. (Gemini API)

### 3. 위험도 예측
공공데이터에서 수집한 공동주택 단지 정보와 공시가격 데이터를 구축해, 입력한 주소의 전세 위험도를 예측합니다. (LightGBM)
